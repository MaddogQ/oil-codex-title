# oil-codex-title 管理技能

本技能随完整插件安装，用于预览和管理话题标题、查看用量。自动命名由插件的后台 Hook 执行。

个人 fork 使用 `YYMMDD [类别] 对象｜目标`，明确完成后增加前置 `✓ `。日期来自真实 `createdAt` 的本机时区日期，状态可以重新激活；不主动迁移旧标题，也不自动归档。

## 使用

安装后可以说“预览这个话题的新标题”“暂停自动命名”或“查看命名用量”。安装入口和功能说明见[插件 README](../../README.md)，操作流程见 [SKILL.md](SKILL.md)。请安装完整插件，单独复制此技能目录不会包含后台程序。

## 兼容性与依赖

需要 Python 3.10+、已登录的本地 Codex CLI 和宿主工具。上游 macOS 实测与跨平台自动化记录属于旧策略；本 fork 的新策略不能据此宣称 Desktop 已验收。Windows 后台 Hook 需要PATH 中可用的 Python 3.10+。云端不支持后台入口。

## 数据与权限边界

命名读取近期对话并使用账号模型额度，只改标题元数据，不往原话题添加消息。上游独立归档实现保留并默认关闭，completion 不触发归档。模型选择和调用参数沿用上游现有配置。用量账本不保存对话原文。
